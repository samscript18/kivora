# Three-minute demo

1. **0:00–0:20 — The problem.** “One quiet manual override can erase thousands before a revenue manager notices.” Show the live integration status.
2. **0:20–0:50 — Detection.** Open the Skyview Suite incident. Highlight the root cause, $6,711 exposure, confidence and Wheelhouse evidence.
3. **0:50–1:25 — Proof before action.** Run the live Wheelhouse preview. Emphasize that the preview uses current account data and does not mutate pricing.
4. **1:25–1:55 — Human control.** Approve the correction. Kivora clears the override, enables automatic posting, syncs the channel and verifies the preference.
5. **1:55–2:20 — Close the communication loop.** Show the grounded owner brief and audit trail.
6. **2:20–2:45 — Portfolio leverage.** Visit Portfolio, Opportunities and Telegram to show continuous monitoring at scale.
7. **2:45–3:00 — Expansion.** Underwrite an address and close with: “Kivora does not replace revenue managers. It makes sure they find the opportunity first.”

## Backup plan

If Wheelhouse or MongoDB is unavailable, Kivora displays the real integration error and blocks dependent workflows. No screen substitutes synthetic data or falsely claims a live mutation.
